# 高中数学教学资料库

面向新高考地区考生的数学教学资料与课件仓库。备课、出题、课件版本管理都在这里。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `课件/` | 按章节建子文件夹，存 PPT 与讲义 |
| `学案与习题/` | 学案、试卷、题库文档 |
| `网页课件/` | HTML 互动课件，可发布为网页给学生访问 |
| `素材/` | 图片、GeoGebra 文件、公式截图 |

## 命名规范

格式：`章节号-内容-学期`，例如：

- `课件/第二章 函数/2.3-二次函数图像-2026秋.pptx`
- `学案与习题/高二基础进阶/01-集合与常用逻辑用语-学案.docx`

禁止使用「最终版」「真最终版」「修改版」「副本」等后缀。要保留旧版本就重新提交一次，GitHub 会自动记住每一次历史。

## 常用操作

### 上传资料
进入仓库 → Add file → Upload files → 拖入文件 → Commit changes。

### 新建文件夹
上传时在文件名框输入带斜杠的路径即可，例如 `课件/第三章 导数/3.1-导数的概念.pptx`，斜杠自动创建目录。

### 记教学待办
Issues → New issue → 写下要做的事 → 完成后 Close issue。

### 查看历史 / 回退
仓库首页右侧 Commits 是全部历史版本；打开任意文件 → History 查看改动记录。

### 发布网页课件（学生可访问）
1. 把 `.html` 文件上传到 `网页课件/`
2. Settings → Pages → Branch 选 `main` → Save
3. 学生访问地址：`https://46361325-gif.github.io/math-teaching/网页课件/文件名.html`

## 注意事项

- 单个文件不超过 100MB（内含大量高清图的 PPT 容易超）
- 仓库是 Public，请勿放入学生姓名、成绩等个人信息；通过 Pages 发布的网页对所有人生效
- Word / PPT 是二进制格式，GitHub 无法逐行对比差异，但每次提交都完整保存一个版本
